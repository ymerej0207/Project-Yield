Project Yield v1.7 - Listed Price Automation

- Fetch Info stores crawled retail price separately as Listed Price.
- Product Value defaults to Listed Price when the creator has not entered an override.
- Manual Product Value overrides are preserved separately.
- If no public price is found, Product Value remains visually blank for manual entry.
- Expected product value is visible but does not count toward Product Value Received until received.
- No paid APIs or AI services.
