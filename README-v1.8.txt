Project Yield v1.8 - Deeper Price Intelligence

- Searches JSON-LD offers, product price meta, Open Graph price, embedded/hydration JSON price fields, list/MSRP fields, and constrained visible price text.
- Separates Listed Price and Current Price.
- Product Value defaults to Current Price, then Listed Price, unless manually overridden.
- Shows the price extraction source in intake for debugging.
- No paid APIs, scraping services, or AI credits.

Deploy:
1. npx supabase db push
2. npm run build
3. git add .
4. git commit -m "Project Yield v1.8 Deeper Price Intelligence"
5. git push
